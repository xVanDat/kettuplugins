# CustomProfileEnhanced (Kettu / Vendetta / Bunny Mobile Port)

A full-featured mobile port of **CustomProfileEnhanced** for **Kettu**, **Bunny**, **Revenge**, and **Vendetta**.

## Installation

Paste either of the following URLs into **Settings -> Plugins -> Install a plugin (`+`)** in Kettu:

- Root URL: `https://xvandat.github.io/<repo-name>/`
- Subfolder URL: `https://xvandat.github.io/<repo-name>/CustomProfileEnhanced/`

## Features

- **Profile Information**: Custom Username, Display Name / Nickname, About Me / Bio, Pronouns, Discord Member Since date, Local Email & Phone display.
- **Appearance & Nitro**: Local Nitro status, Avatar URL, Banner URL, Primary & Secondary Profile Gradient Colors, Quick Color Presets.
- **Collectibles (Shop SKU / Link)**: Avatar Decoration, Profile Effect, Nameplate, and Profile Frame resolved directly from Discord Shop links or SKU IDs.
- **Badges**: All 12 standard Discord Badges, 9 Evolving Nitro Badges, 4 Special Badges (Completed a Quest, Orbs, Old Username, Level Reached), 6 Gifting Badges, and 9 Server Boost Badges.
- **Profile Connections**: Add verified fake profile connections across 22 platforms.
- **Fake Account Switcher & Local Custom Statuses**: Add any User ID to the Account Switcher, preview switching, restore real account, and set local custom statuses for any user.
- **Global Badges**: Fetch and filter badges from `badges.equicord.org` across 16 client mods.
