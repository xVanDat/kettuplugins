# Kettu Plugins by xVanDat

Collection of custom plugins for **Kettu**, **Bunny**, **Revenge**, and **Vendetta** Discord mobile mods.

---

## 1. DiscordAppLock (Native iOS Biometrics & Privacy Overlay)

Khoá bảo vệ Discord bằng **Touch ID / Face ID** & **Mật mã iPhone**, kèm tính năng **che mờ hoặc hiện Logo Discord** trong App Switcher (Đa nhiệm) không delay.

### Cài đặt Plugin vào Kettu:
Dán một trong các đường link sau vào **Settings -> Plugins -> Install a plugin (`+`)**:

- **GitHub Pages:** `https://xvandat.github.io/kettuplugins/DiscordAppLock/`
- **GitHub Raw:** `https://raw.githubusercontent.com/xVanDat/kettuplugins/main/DiscordAppLock/`

### Tính năng:
- **Xác thực Touch ID / Face ID / Mật mã:** Tích hợp với Tweak Native iOS.
- **Tùy biến lời nhắn (Subtitle):** Tự đổi dòng chữ hiển thị dưới bảng Touch ID / Face ID (như *"Mở khoá tin nhắn bí mật"*).
- **Che nội dung trong App Switcher:** Nền tối kèm Logo Discord (Splash) hoặc hiệu ứng Blur làm mờ sâu.
- **Thời gian tự động khoá:** Ngay lập tức, 30 giây, 1 phút, 5 phút.

## 2. CustomProfileEnhanced (Mobile Port)

A full-featured mobile port of **CustomProfileEnhanced** for mobile Discord client mods.

### Cài đặt Plugin vào Kettu:
Dán một trong các đường link sau vào **Settings -> Plugins -> Install a plugin (`+`)**:

- **GitHub Pages:** `https://xvandat.github.io/kettuplugins/CustomProfileEnhanced/`
- **Root URL:** `https://xvandat.github.io/kettuplugins/`

### Tính năng:
- **Profile Information**: Custom Username, Nickname, About Me, Pronouns, Join Date, Local Email/Phone.
- **Appearance & Nitro**: Local Nitro status, Avatar URL, Banner URL, Profile Gradients.
- **Collectibles**: Avatar Decoration, Profile Effect, Nameplate, Profile Frame from Discord Shop.
- **Badges**: Standard Badges, Evolving Nitro, Special Quest/Level Badges, Server Boost Badges.
- **Profile Connections**: Add verified fake connections across 22 platforms.
- **Fake Account Switcher & Custom Statuses**: Add any User ID, preview switching, local custom statuses.
- **Global Badges**: Fetch badges from `badges.equicord.org`.
